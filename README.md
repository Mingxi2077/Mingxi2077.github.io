# eden* ｜ 地球上最后的恋爱物语

> **Because you live, I live.**
> —— 因为你活着，所以我活着。

一个献给 minori 视觉小说《eden* — They Were Only Two, On The Planet》的个人赏析站点。

如果末日已经注定，爱情还有意义吗？这个网站想回答的，正是这个问题。

## 关于《eden*》

2009 年 9 月 18 日，曾制作《ef - a fairy tale of the two.》的 minori 推出了这部「地球上最后的恋爱物语」：一颗「灭世之星」让地球只剩百年，人类造出人造天才「菲利克斯」完成逃离计划；而计划的中枢——白发少女诗音，在完成使命后失去了自由。看守她的年轻士兵榛名亮，将与她共度这颗星球上最后的时光。

监督御影、剧本镜游、人设ちこたむ、音乐天门、特别感谢新海诚——一支群星般的制作阵容，讲述了一个极其简单的故事：在世界终结之前，两个人相遇、相恋、离别。

## 本地运行

本站没有构建步骤或运行时依赖。克隆仓库后，在仓库根目录启动任意静态文件服务器即可：

```bash
python -m http.server 8000
```

随后访问 `http://localhost:8000/`。不建议直接双击打开 `index.html`，通过 HTTP 访问更接近 GitHub Pages 的实际环境。

## 项目结构

```text
.
├── index.html       # 页面内容与语义结构
├── css/style.css    # 视觉系统、动画与响应式布局
├── js/main.js       # 导航、剧透、音乐、OP 与灯箱交互
└── assets/
    ├── audio/       # 站内播放的游戏原声
    └── cg/          # 页面与绘卷使用的游戏 CG
```

提交前运行 `node scripts/verify.mjs`，检查内部资源、站内锚点、图片替代文本、画廊数量及文档同步状态。
